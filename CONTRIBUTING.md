# Contributing

This repository is **public** open source. Issues, pull requests, comments, and attachments are visible to the internet.

## Before you submit

**Do not post secrets here.**

Do not include any of the following in an issue, PR, comment, or image:

- Secrets, tokens, passwords, connection strings, or credentials
- Azure subscription IDs, tenant IDs, or object IDs
- Customer PII or workshop operational data
- kubeconfigs or tfvars

**Screenshots and screen recordings count.** Workshop customer names, phones, vehicles, invoices, or similar data in an image is still public disclosure. Redact first.

Security vulnerabilities and secret exposure: follow [SECURITY.md](SECURITY.md). Open a public issue titled `Security contact request`, @mention `cookieofcode`, and include **zero** vulnerability detail, PoC, secrets, or screenshots of the bug. Do not use a self-serve advisory reporter form.

Product, bug, and docs work: use the issue templates. See [agents/COS_INTAKE.md](agents/COS_INTAKE.md).
